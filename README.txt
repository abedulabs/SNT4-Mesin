MAKMAL MESIN RINGKAS 2.5D — GAYA BANDAR HIJAU 3D
Pakej simulator responsif dengan latar pentas, bayang, warna berlapis dan ilustrasi 2.5D.
Enam simulator: tuas, takal, roda dan gandar, baji, satah condong, skru.
Kuiz objektif 10 markah; simulator 12 markah; soalan saintifik 28 markah; jumlah 50.
Kawalan simulator menggunakan slider dan kotak nilai yang boleh ditaip. Tekan dan tahan butang daya untuk gerakan.
Soalan saintifik memberikan anggaran kata kunci; guru perlu menyemak jawapan.

UPLOAD GITHUB PAGES:
1. Ekstrak ZIP.
2. Gantikan index.html dalam root repository.
3. Commit changes dan buka semula laman GitHub Pages.

Kemas kini simulator skru: keratan sisi botol plastik, ulir pada leher botol dan ulir dalaman penutup ditunjukkan. BUKA memutar lawan jam sambil penutup naik; KUNCI memutar ikut jam sambil penutup turun dan mengetat. Semua lima simulator lain dikekalkan.
